### P2 확장프로그램은 전용 프로필에 1회 설치 (v2.1.53)

P2 는 평소 쓰는 Chrome 이 아니라 **전용 프로필**(`P2/.chrome-profile`)로 Chrome 을
새로 띄웁니다 — Chrome 136 부터 원격 디버깅이 기본 프로필에서 무시되기 때문입니다.
게다가 Chrome 137 부터는 정품 Chrome 에서 `--load-extension` 이 제거되어 저장소에
동봉한 확장 폴더도 로드되지 않습니다.

그래서 **최초 1회만** P2 가 띄운 Chrome 창에서 웹스토어로 더망고 확장을 설치하세요.
확장이 없으면 P2 가 설치 페이지를 자동으로 띄우고, 수동 로그인 대기와 똑같이
**[Chrome에 추가] 를 누를 때까지 기다렸다가 그 자리에서 이어서 진행**합니다
(최대 600초, 보드 **[수집 종료]** 로 즉시 취소 가능). P2 를 다시 실행할 필요는
없습니다. 설치 내용은 전용 프로필에 남으므로 다음 실행부터는 대기 없이 지나갑니다.

평소 Chrome 에 이미 설치돼 있어도 P2 창에는 적용되지 않습니다 (프로필이 다름).

### P2 더망고 로그인 · 1·2행 스크린샷

수집 시작 → 더망고 **로그인창이 열림** → **브라우저에서 직접 로그인**  
실행로그: **모든 입력**의 `최종 카테고리명` / `최종 카테고리 URL주소` 기록  
**1·2행 전과정 스크린샷** 체크 시: 입력 1·2행 단계별 PNG 저장  
→ 보드 **[스크린샷 보기]** 또는 `P2/run-logs/<시각>/index.html` 갤러리

### P3_필터_갱신 실행로그 — MAIN / SUB / 스크린샷 3단 그리드

실행로그 상단 **체크박스 3개**(MAIN · SUB · 스크린샷)로 각 영역을 켜고 끕니다.

| 영역 | 내용 |
|------|------|
| **MAIN** | **1~7단계만** — 실패한 단계는 그 단계 행에 적색 표시 |
| **SUB** | 선택한 MAIN 단계의 세부내용 (화면상태·엑셀매칭·오류사유 등) |
| **스크린샷** | 선택한 단계의 캡처 — **더블클릭으로 PNG 열기** (오류/원인 파악용) |

- **2단계**: 망고 행 정보를 **그대로** 표출 (필터명·URL 검색·수집계수·전체저장 …)
- **5단계**: **상품수 갱신전 → 갱신후** 를 `저장하기` 로그에 표출
- 망고 행 「URL 검색」 주소는 **엑셀 비교(KEY)로만** 사용 — 그 주소로 화면을 열지 않음
  (상품수 읽기 로직은 전부 주석처리)
- 처음 **5개 처리행**은 `수집조건수정` · `저장하기` · `확인` 뒤 **각 3초 대기**(화면 변화
  확인용), **6번째 행부터는 지연 없이 최고속**
