## 4. 반복되는 불명확 패턴 (과거 SR·운영에서 관측)

1. **미래형 범위** — “앞으로 추가할 것임” → 이번 PR에 넣을지 애매.
2. **이름만 있는 신규 레포** — GitHub 생성 권한이 에이전트에 없으면 막힘(병렬 Mango 런에서 관측).
3. **제목≠본문** — 런 이름만 있고 본문 독촉만 전달되면 작업 시작이 지연됨(본 런).
4. **완료 기준 생략** — “수정해”만 있고 테스트·버전·아이콘 반영 여부 미기재.
5. **유효 요건 인덱스 부재** — SR는 많지만 “지금 살아 있는 규칙” 한 장 요약이 없음.
