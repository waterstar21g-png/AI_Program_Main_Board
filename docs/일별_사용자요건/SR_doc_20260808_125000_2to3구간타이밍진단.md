전체를 다시 훑어봤고, 이전 커밋(v2.0.50)에서 이미 코드가 직접 넣던
블라인드 sleep(800ms/1000ms/500ms)은 모두 제거되어 있음을 확인함.
남아있는 유일한 대기는 `url_search_button(...).wait_for(state="visible")`
— 이건 "블라인드 sleep"이 아니라 실제로 그 버튼이 화면에 나타날 때까지
필요한 만큼만 기다리는 것으로, 버튼이 뜨기 전에 3항(URL 입력)을 시도하면
반드시 실패하므로 없앨 수 없음.

즉, 남은 지연이 있다면 코드가 인위적으로 넣은 게 아니라 실제 사이트의
메뉴 클릭 → 페이지 전환/서버응답/렌더링에 걸리는 시간일 가능성이 높음.
다만 이 환경에서는 실제 사이트에 접근할 수 없어 직접 재현·확정할 수
없으므로, 다음 실행에서 정확한 원인을 바로 알 수 있도록 구간별
소요시간 진단을 추가함.
