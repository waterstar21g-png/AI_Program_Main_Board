6. 오류 원인 (사용자 질문 「오류의 원인은?」에 대한 답):

`P3_필터_갱신/update_filters.py` 는 이미 P2와 동일한 MAIN/SUB 프로토콜
(`##MAIN##seq##n##msg` · `##SUB##seq##msg`)로 표준출력에 로그를 보내고 있었으나,
보드(`board/app.py`)의 P3 로그 처리부가 그 마커를 **해석하지 않았다**.

- `_watch_p3_proc` 는 `##P3SHOT##` 과 `[단계] 메시지` 두 형식만 알아보고,
  나머지 줄은 통째로 단일 그리드(`self.p3_log`)의 「내용」 칸에 그대로 넣었다.
  → 그래서 화면에 `##MAIN##137##90##…` 같은 마커 원문이 그대로 보였다.
- P2는 `_handle_collect_line` → `log_protocol.parse_line` → MAIN/SUB 두 그리드로
  나누는데, P3 탭에는 그리드가 1개뿐이고 파서도 없었다 (구분이 안 된 진짜 이유).
- 추가로 `_is_major_log` 가 메시지 첫머리의 `N)` 로 MAIN 여부를 자동판정해서,
  스크린샷 라벨(`6)확인 클릭 실패 -> ….png`)까지 MAIN 에 섞여 있었다.
