6. 반영 내용
- 기존 Next.js 웹앱의 UI(좌측 메뉴·우측 업로드/실행/라이브로그)는 그대로
  유지하고, 백엔드(runner.ts / browser-session.ts)에 python-collector에서
  검증된 수정사항을 전부 이식:
  a) TMG_MAIN_URL(admin.php) 추가 — 로그인 화면을 거치지 않고 메인화면
     에서 시작, 세션 살아있으면 자동 진입
  b) safeGoto / withNavRetry 추가 — "interrupted by another navigation",
     "Execution context was destroyed", "Target closed" 오류 시 페이지
     안정 대기 후 최대 3회 재시도 (reset_to_bulk_menu·waitBulkReady·
     urlInput 전부 적용)
  c) refreshIfClosed — 로그인 중계 페이지가 자기 탭을 닫는 경우 살아있는
     새 탭을 다시 찾아 복구
  d) urlInput 3단계 정밀 탐색으로 교체 (같은 tr → 상위요소 후보 1개 →
     최대 rows textarea) — 엉뚱한 필드에 입력되는 문제 방지
  e) clickIt: 네이티브 클릭 실패 시 좌표기반 신뢰 클릭 우선, 최후에만
     JS강제클릭(비신뢰) 사용
  f) waitPopupsGone: 팝업이 전혀 안 뜨면 경고+키보드 재시도+그래도
     없으면 명확한 오류로 중단 (예전엔 조용히 다음 단계로 진행)
  g) /api/product-collect/open 이 TMG_MAIN_URL로 열도록 변경
- 검증: 타입체크 통과, 프로덕션 빌드 성공, dev 서버 기동 후
  /api/product-collect/run 실제 호출해 정상 JSON 응답 확인
  (엑셀 없음 케이스: {"ok":false,"message":"엑셀 행이 없습니다"})
  → "Failed to fetch"는 dev 서버 미기동/구버전 캐시 때문으로 판단,
  최신 동기화 후 재확인 요청
