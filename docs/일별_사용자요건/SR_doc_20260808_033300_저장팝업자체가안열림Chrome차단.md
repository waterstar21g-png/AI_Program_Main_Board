6. 정정된 이해 및 조치:
"팝업창 모달"이 오판되는 게 아니라 클릭 후 실제로 전혀 열리지 않는
문제로 재정의하고 원인을 재검토함.

가장 유력한 근본원인: 이 프로그램은 사용자가 평소 쓰는 실제 Chrome을
디버그 포트로 띄워 붙는 구조(Playwright 전용 Chromium 아님). 실제
Chrome은 팝업차단이 기본 ON이며, 저장하기 클릭이 브라우저 입력단에서는
trusted(진짜 클릭)여도, 사이트가 저장 AJAX 완료 콜백 등에서 "비동기로"
window.open()을 호출하면 Chrome은 이를 사용자 제스처와 분리된 호출로
보고 조용히 막아버림 — 이 경우 팝업 Page 객체 자체가 생성되지 않으므로
어떤 탐지 로직을 써도 "정말로 없는" 상태가 됨(오판이 아님).

조치:
- launch_debug_browser() 의 Chrome 실행 인자에
  --disable-popup-blocking 추가.
- 이 플래그는 Chrome을 새로 켤 때만 적용되므로, 기존에 이미 열려 있던
  Chrome을 재사용 중이면 여전히 막힐 수 있음 — 마커 파일로 감지해
  "Chrome을 완전히 종료 후 다시 실행하세요" 경고를 로그에 남기도록 함
  (warn_if_reusing_pre_fix_browser).
- 클릭 후 새 창이 0개일 때(진짜로 안 열린 상황) 오류 메세지에 이
  원인·조치를 직접 포함하도록 wait_save_execution_popup 개선.
- 클릭 신뢰도 보강: 클릭 전 실제 마우스 호버(mouseenter 의존 버튼 대비)
