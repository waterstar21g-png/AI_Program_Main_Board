## 이번에 추가로 개선한 것

v2.1.52 는 웹스토어 설치 페이지를 띄운 뒤 그대로 실패 처리해서, 사용자가 확장을
설치한 다음 P2 를 한 번 더 실행해야 했다. 같은 화면("확장프로그램 설정 실패")을
또 보게 되므로 혼란스럽다.

- `P2/collect.py`
  - `EXT_INSTALL_WAIT_SEC = 600` 추가.
  - `wait_for_extension_install()` 신규 — 수동 로그인 대기(`wait_for_user_login`)와
    동일한 방식으로 확장 팝업 주소가 열릴 때까지 폴링. 보드 [수집 종료]
    (`check_stop`) 로 즉시 취소 가능.
  - `open_extension_install_page()` 가 연 웹스토어 탭을 설치 확인 후 닫는다.
  - `ensure_mango_extension_settings()`: 설치 확인 시 그 자리에서 이어서 진행.
    확인 시점 스크린샷 `ext_installed` 추가.
- `P2/tests/test_launch_flags.py`: 대기 성공 / 타임아웃 / 수집종료 취소 3건 추가 (총 8건).
- `README.md`, `P2/README.md`, `P2/extensions/README.md`, `VERSION.txt` 갱신.
