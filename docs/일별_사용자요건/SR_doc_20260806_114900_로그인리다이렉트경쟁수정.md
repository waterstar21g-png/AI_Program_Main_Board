6. 반영 내용
- 원인: 사용자가 로그인 후 Enter를 누른 시점에, cafe24 사이트 자체가
  m_login_ok.php -> admin.php로 자동 리다이렉트 중이었고, 그와 거의 동시에
  스크립트도 admin.php로 이동을 시도해 Playwright가
  "interrupted by another navigation" 오류를 던지며 프로그램이 죽음
- safe_goto() 추가: 이 오류가 나면 진행 중인 사이트 자체 리다이렉트가
  끝날 때까지 짧게 대기 후 최대 3회 재시도
- ensure_ready_page(): 로그인 대기(Enter) 직후 곧바로 이동하지 않고
  먼저 페이지가 안정될 때까지(domcontentloaded) 기다린 후, 그래도
  로그인 화면/다른 도메인이면 그때만 safe_goto로 이동
- wait_bulk_ready / reset_to_bulk_menu의 직접 goto 호출도 모두 safe_goto로 교체
- 검증: 로그인 리다이렉트 체인과 스크립트의 이동 시도가 겹치는 레이스 상황을
  로컬 mock 페이지로 5회 반복 재현 — 전부 대량수집 화면까지 정상 도달 확인
