- `collect.py` 표준출력 프로토콜 신설: `##MAIN##<seq>##<n>##<msg>` (단계),
  `##SUB##<seq>##<msg>` (추가정보), `##SUBSHOT##<seq>##<path>##<label>` (스크린샷).
  seq는 단계 "발생"마다 매기는 고유번호로, 같은 단계번호가 여러 행에서
  반복돼도 main 특정 행 ↔ sub 정보가 정확히 1:1로 이어지게 함.
- main 그리드에서 행(단계 발생) 클릭 시 `<<TreeviewSelect>>` 로 해당 seq의
  sub 정보만 다시 그려서 보여줌. 최신 행을 보고 있을 때는 새 단계가 생길
  때마다 자동으로 따라가고(follow), 과거 행을 클릭하면 그 스냅샷에 머무름.
- sub 그리드의 스크린샷 항목은 더블클릭으로 해당 이미지 파일을 바로 엶.
- 파싱 로직은 tk 의존 없는 `board/log_protocol.py`로 분리해 유닛테스트 가능
  (8/8 PASS). 기존 `board/log_format.py`(1~5단 들여쓰기 방식)는 이 설계로
  완전히 대체되어 삭제함.
