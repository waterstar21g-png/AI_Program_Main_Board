6. 반영 내용

  로그 파일(.chrome-profile/chrome_debug.log)로 교체
  → 샌드박스 테스트에서 DEVNULL로 버릴 때 Chrome이 시그널(SIGTRAP)로
    즉시 죽는 현상을 확인(poll=-5). Windows 환경에서도 특정 보안
    소프트웨어와 충돌 시 유사하게 조용히 죽을 수 있는 위험한 패턴이라
    판단해 안전한 방식으로 교체
- 디버그 포트 연결 대기 중 3초마다 "아직 대기 중..." 진행 로그 출력
  (기존엔 최대 30초간 완전히 조용해서 멈춘 것처럼 보일 수 있었음)
- 이전 실행이 비정상 종료돼 남은 SingletonLock 등 잠금파일을 새로 실행
  전에 정리(안전 조건: 디버그포트가 이미 열려있지 않을 때만)
- 대량수집 화면 로딩 확인 직전에도 진행 로그 추가
- 브라우저가 안 열리면 참고용 chrome_debug.log 경로를 안내 메시지에 포함
- 참고: "반응 없음"이 정확히 어느 단계(브라우저 실행 직후 / 로그인 후 /
  검색 클릭 후 등)인지 사용자에게 재확인 요청 — 로그 마지막 줄과
  Chrome 창이 실제로 떴는지 여부를 다음 보고에 포함해달라고 안내
