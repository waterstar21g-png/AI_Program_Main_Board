A. 모든 상품 수집의 세부 단계와 처리 로직은, 그리고 필수적 순서는?

 1. 로그인 -> 
 2. 상품수집 필드 초기화 : 상품데이터수집 -> 상품데이터 대량수집
 3. 상품수집 url정보 입력 : 
   엑셀 "최종 카테고리 URL주소" 필드값을 "url상품검색하기" 입력필드에 입력
 4. 상품수집 시작 :  버튼명 "URL상품검색하기" 클릭 
 5. 상품수집 실행 : "팝업 모달창" 열린후 계속 떠 있음 
     --> 수집된 상품을 로컬의 임시 메모리에 계속 추가하는 단계
 6. 상품수집 종료 : "팝업 모달창" 닫기 - 확인
     --> 수집된 상품을 로컬의 임시 메모리에 보관 완료하는 단계
 7. 수집된 상품 저장범위 지정 : DB서버에 저장할 범위정보를 지정
     --> "선택상품저장" 또는 "검색된 상품 모두저장" 둘중 하나를 클릭하여 선택함
 8.  수집 상품 필터 및 수집상품갯수 <항목필드값>에 입력
     --> 엑셀 데이터 정보를 그대로 반영함 (단, 상품수는 최소 수집건수 3을 입력)
     --> 나머지 상품은 해당 필터값을 통해 일괄 자동화 수집이 가능함
 9.  수집 상품 DB저장하기 시작 : "저장하기" 버튼 클릭시 DB에 저장을 시작하게됨
10. 수집 상품 DB저장하기 실행 :  "팝업 모달창"이 열린경우, 
      --> 수집 상품이 망고 DB서버에 "계속 저장중 상태" 를 표시함.
11. 수집 상품 DB저장하기 종료 :  "팝업 모달창" 닫기 - 반드시 확인
       --> 수집 상품이 DB에 "저장 완료" 되었음을 의미하고 ,모달창을 중간에 
             닫으면 DB저장이 중단되고 ROLLBACK됨 (초기화도 마찬가지 의미)
12. 수집후 DB에 최종 저장된 건수 로그 : 망고 자체 정보화면에 나타냄
       -> "00"건 수집 되었음. 수집완료를 동시에 나타냄
13. 수집전 회면 초기화 : 다음 행 데이터의 상품을 수집하기 위한 필요조치임
14. 이후는,  3. ~ 12.를 반복 수행함
