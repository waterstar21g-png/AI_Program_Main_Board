6. 원인 규명 (치명적 버그 확정):
- `main()`의 행 반복 루프에서, 2번째 이후 입력행 진입 전 호출하는
  `ensure_overlays_closed_before_next()`를 감싼 예외 처리가:
  ```
  except RuntimeError as e:
      if "수집 전 팝업/모달이 닫히지 않음" in str(e):
          ...fail+=1; continue...
      raise   # <- 이 문구가 아닌 RuntimeError, 또는 RuntimeError가
                  아닌 다른 예외(Playwright TimeoutError/TargetClosedError 등)는
                  전부 여기서 raise 되어 루프 전체가 그대로 죽음
  ```
  였음. `main()`을 감싼 바깥 try는 `except CollectStopped`만 잡으므로,
  그 외 예외는 아무도 못 잡고 파이썬이 처리되지 않은 예외로 프로세스를
  종료시킴. 이 traceback은 `##MAIN##/##SUB##/##META##` 마커가 없어
  보드 화면에는 전혀 표시되지 않음(마커 없는 줄은 화면에 안 보이는
  설계) — 그래서 사용자에게는 "화면이 그냥 멈춘 것"처럼 보였음.
  스크린샷의 순번1·완료건1(1행은 성공, 2행 진입 준비 중 죽음)이 정확히
  이 경로와 일치함.
- v2.0.53에서 "엑셀 2개만 처리하고 중단하는 문제"를 고쳤다고 했었지만,
  이번 케이스는 그 수정과 무관한 **완전히 별개의 재발 지점**(다음행
