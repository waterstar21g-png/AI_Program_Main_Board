## 반영 내용

### 1. 망고보드 가져오기

`cursor/mango-helper-ai-board-0c73` 브랜치에만 있던 망고보드
(`Mango_Helper_AI_Board/`, 192개 파일)를 `main` 계열로 머지했다. 그 브랜치는 main
tip 위에서만 자라 있었고 루트 파일을 하나도 건드리지 않아, AI보드 소스는 그대로다.

포함 프로그램: 망고보드 메인 UI · P1_필터단위_마진정책적용 ·
P2_필터단위_상품수변경 · P2(더망고 대량수집) · P3_필터_갱신 · P3_핏클상세페이지.

### 2. AI보드와 별개의 독립 보드로 고정 (원문 2)

망고보드를 AI보드의 프로그램 목록에 **넣지 않았다.** 별도 보드로만 표기한다.

| 파일 | 내용 |
|------|------|
| `README.md` (루트) | "별도 보드 — 망고보드" 절 신설 — 실행·버전·문서·PC폴더 분리표, AI보드 무영향 명시 |
| `PROJECTS.md` (루트) | "별도 보드 (AI보드 프로그램 아님)" 표 — P1~P3 목록과 분리 |
| `Mango_Helper_AI_Board/README.md` | "★ AI보드와 별개의 독립 보드" 절 신설 |
| `Mango_Helper_AI_Board/REPOSITORY.md` | AI board 와의 관계를 "별개의 독립 보드" 로 재작성 |

독립성 근거(코드 확인):

- 경로: `board/app.py` · `board/library.py` · `board/self_update.py` · `scripts/launch.py`
  모두 `Mango_Helper_AI_Board` 폴더를 루트로 계산 — 상위(AI보드) 탈출 없음
- 갱신: `board/self_update.py` 의 `REPO = waterstar21g-png/Mango_Helper_AI_Board`,
  `DEFAULT_BRANCH = main` — 자기 저장소 기준
- 버전: 자체 `VERSION.txt` 를 읽음 (AI보드 루트 VERSION 과 무관)
- AI보드 소스를 import 하는 코드 없음 (`terms.py` 의 이름 구분 상수만 존재)

### 3. 개발 브랜치 참조 정리

main 으로 들어왔으므로 설치·업데이트 경로의 clone/pull 대상을 바꿨다.

| 파일 | 변경 |
|------|------|
| `망고보드_한번에설치.bat` | 부모 폴백 clone `-b cursor/mango-helper-ai-board-0c73` → `-b main` |
| `scripts/install-all.ps1` | `$ParentBranch` → `main` |
| `scripts/pull-update.ps1` | 부모 저장소 fetch/pull → `main` |
| `programs/registry.json` | `parent_branch` → `main` |
| `PC_SETUP.md` · `PC_준비완료.md` · `PC_클론가이드.md` · `GITHUB_SETUP.md` · `README.md` · `REPOSITORY.md` | 브랜치 안내 → `main` |

독립 repo 우선 → 없으면 부모 `main` 폴백 순서는 그대로 유지.

`docs/일별_사용자요건/` 의 과거 SR 문서는 **당시 기록이라 수정하지 않았다.**
