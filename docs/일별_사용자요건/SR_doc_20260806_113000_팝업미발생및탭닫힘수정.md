- (A) 로그인 후 탭이 닫히는 문제(TargetClosedError):
  cafe24 로그인 중계 페이지가 로그인 성공 후 원래 탭을 닫고 새 창을
  띄우는 경우가 있음 → refresh_if_closed() 추가: 탭이 닫혔으면 같은
  브라우저에서 살아있는 탭을 다시 찾아옴. ensure_ready_page가 최신
  page를 반환하도록 변경하고 main()/행 루프에서도 매번 갱신
- (B) click_it() 개선: 네이티브 클릭 실패 시 좌표기반 실제 마우스
  클릭(신뢰됨)을 먼저 시도, 그것도 안 되면 최후수단 JS강제클릭(비신뢰,
  팝업이 차단될 수 있음)을 쓰고 경고 로그 남김
- (C) wait_popups_gone에 "그 시간 동안 팝업이 한 번도 안 뜨면 경고"
  기능 추가. URL검색 클릭 후 팝업이 전혀 안 뜨면: 키보드 Enter로
  재시도 → 그래도 없으면 명확한 오류로 중단(예전엔 조용히 다음
  단계로 진행해 원인을 알 수 없었음)
