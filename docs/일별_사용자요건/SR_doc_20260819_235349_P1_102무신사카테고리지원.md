6. 반영 내용 요약:

- **무신사(musinsa.com) 지원 추가**: 사이트 URL에 "musinsa.com"이 포함되면 A-RT(ABC마트)
  방식 대신 무신사 카테고리 메뉴(`https://www.musinsa.com/menu/category`) 방식으로 자동
  분기(`is_musinsa_platform`, `_crawl_musinsa`).
- **상위 카테고리명 = 성별 탭**("전체"/"남성"/"여성", `data-section-name="gender_tab"`)
  — Playwright로 실제 탭을 클릭해 성별별 메뉴를 가져온다(`fetch_musinsa_menu_html`).
- **중위 카테고리명 = 좌측 1depth 목록**(뷰티·신발·상의 등, `data-section-name=
  "catemenu_left"`) — ★매우 중요: 스크린샷에 표시되는 좌측 목록에 있는 이름만 중위로
  인식하고, 그 외(상단 서비스탭 등)는 인식하지 않음(`parse_musinsa_menu_tree`).
- **하위 카테고리명 = 우측 버튼**(`data-section-name="catemenu_right"`) — "신상품 보기"·
  "전체 보기"는 제외. 신발·스포츠/레저·키즈·어스처럼 하위그룹이 더 나뉜 경우 "품목별"
  그룹만 인식하고 "인기 라인업"(브랜드 모음) 등은 제외.
- **최종카테고리명**: 기존 조합식(사업자명-사이트명상위카테고리명-중위카테고리명-
  하위카테고리명)을 그대로 적용.
- **상품수집필터 URL**: 하위 카테고리 버튼의 실제 이동 URL을 사이트 리다이렉트(307)로
  확정 — 기존 쿼리(`separatorId` 등)는 보존하고 성별(`gf`)만 덧붙임
  (`resolve_musinsa_category_url`).
- 실제 musinsa.com에 접속해 원문 1·4의 예시 두 건을 그대로 실행 → 결과 URL이 사용자
  제공 URL과 완전히 일치함을 확인.
  - 남성>뷰티>스킨케어 → `https://www.musinsa.com/category/104001/goods?gf=M`
  - 여성>신발>스니커즈 → `https://www.musinsa.com/category/103004/goods?separatorId=9&gf=F`
