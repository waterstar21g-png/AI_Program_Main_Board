# 에이전트 안내 (상시)

**전체 규칙의 진입점:** 루트 [`AGENTS.md`](../AGENTS.md)  
(Cursor가 세션마다 자동으로 읽는 위치. 여기 문서만 보면 규칙이 빠질 수 있다.)

사용자에게 **요구하지 않아도** 아래를 지킨다. 상세·보고 폼·버전·SR 규칙은 `AGENTS.md` 를 본다.

## 1. 머지 URL 항상 표시

PR이 열렸거나 머지가 필요한 상태면, 응답에 **머지 URL을 항상** 넣는다.

예:

```
머지 URL: https://github.com/waterstar21g-png/AI_Program_Main_Board/pull/82
```

- 사용자가 “머지 링크 줘”라고 묻기 전에 먼저 표시한다.
- PR 본문 상단에도 `## 머지 URL` 로 동일 링크를 둔다.

## 2. run.bat 별도 실행 안내 금지

머지 반영을 위해 `.\run.bat` / `run.bat --noupdate` 를 **따로 실행하라고 안내하지 않는다.**

로컬 반영 방법(고정):

1. 응답에 **머지 URL** 표시 (필요 시 사용자가 GitHub에서 머지)
2. 바탕화면 **「AI_보드_버전갱신」** 아이콘 한 번  
   → 보드 종료 → GitHub `main` 강제 반영 → 보드 재시작  
   (또는 보드 좌측 하단「머지반영 업데이트」— 종료 후 외부 강제갱신)

`run.bat` 별도 실행 안내는 하지 않는다.  
아이콘이 없으면(최초 1회) `아이콘새로만들기.bat` 만 안내한다.

## 3. 요구사항 원문 없으면 구현 금지

런 제목·브랜치명만으로 기능을 추측해 만들지 않는다. 원문이 없으면 짧게 알리고 원문을 받는다.
