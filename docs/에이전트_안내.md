# 에이전트 안내 (상시)

사용자에게 **요구하지 않아도** 아래를 지킨다.

## 1. 머지 URL 항상 표시

PR이 열렸거나 머지가 필요한 상태면, 응답에 **머지 URL을 항상** 넣는다.

예:

```
머지 URL: https://github.com/waterstar21g-png/AI_Program_Main_Board/pull/82
```

- 사용자가 “머지 링크 줘”라고 묻기 전에 먼저 표시한다.
- PR 본문 상단에도 `## 머지 URL` 로 동일 링크를 둔다.

## 2. run.bat 별도 실행 안내 금지

머지 반영을 위해 `.\run.bat` / `run.bat --noupdate` 를 **따로 실행하라고 안내하지 않는다.**

로컬 반영 방법(고정):

1. 응답에 **머지 URL** 표시 (필요 시 사용자가 GitHub에서 머지)
2. 메인보드 좌측 하단 **「머지반영 업데이트」** 버튼 한 번  
   → 머지 URL 오픈 + GitHub `main` 반영 + 보드 재시작

보드가 꺼져 있을 때만 바탕화면/작업표시줄 아이콘을 안내한다.  
아이콘이 옛 대상을 가리킬 때만(최초 1회) `아이콘새로만들기.bat` 을 안내한다.
