# 상품 수집 14단계 — 필수 순서 (원문 기준)

> 이 문서의 A·B는 사용자 정리 원문을 기준으로 한다.  
> 코드(`P2/collect.py`)는 **6·11·12 확인 없이 다음 단계로 가지 않도록** 게이트한다.

## A. 세부 단계 · 처리 로직 · 필수 순서

| 항 | 단계 | 의미 |
|----|------|------|
| 1 | 로그인 | 더망고 로그인 |
| 2 | 상품수집 필드 초기화 | 상품데이터수집 → 상품데이터 대량수집 |
| 3 | URL 정보 입력 | 엑셀 `최종 카테고리 URL주소` → `url상품검색하기` 입력필드 |
| 4 | 상품수집 시작 | 버튼 `URL상품검색하기` 클릭 |
| 5 | 상품수집 실행 | 팝업 모달창 열림·유지 → 로컬 임시 메모리에 상품 추가 중 |
| 6 | 상품수집 종료 | **팝업 모달창 닫기-확인** → 임시 메모리 보관 완료 |
| 7 | 저장범위 지정 | `선택상품저장` 또는 `검색된 상품 모두저장` |
| 8 | 필터·수집상품수 입력 | 엑셀 반영 (상품수 최소 3) |
| 9 | DB저장 시작 | `저장하기` 클릭 → DB 저장 시작 |
| 10 | DB저장 실행 | 팝업 모달창 열림 → DB에 **계속 저장중** |
| 11 | DB저장 종료 | **팝업 모달창 닫기-반드시 확인** → 저장 완료 (중간 닫기/초기화 = ROLLBACK) |
| 12 | 최종 저장건수 로그 | 망고 자체 화면 `N건이 수집되었음` + 수집완료 |
| 13 | 수집 전 화면 초기화 | 다음 행 수집을 위한 초기화 |
| 14 | 반복 | **3 ~ 13** 반복 (정정) |

> **정정 (사용자):** 14항은 `3. ~ 12.`가 아니라 **`3. ~ 13.`을 반복**한다.  
> 즉 한 사이클 = 3→…→12→13(초기화) → 다시 3 …

## B. 실패의 가장 주요 원인

**6항 · 11항 · 12항 확인 없이 다음 단계로 진행**하면 수집 실패가 발생한다.
