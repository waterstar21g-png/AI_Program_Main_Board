# 에이전트 지시 명확성 평가 (2026-08-20)

## 평가 목적

에이전트가 “할 일이 무엇인지”를 바로 알 수 있도록, 저장소 안 지시 문서의
분산·누락·모호함을 점검하고 **단일 진입점(`AGENTS.md`)** 으로 정리했다.

## 현재 상태 (평가 시점)

| 위치 | 역할 | 문제 |
|------|------|------|
| Cursor User Rules | SR 보관·프론트 디자인 등 | 세션/환경마다 다를 수 있음 |
| `docs/에이전트_안내.md` | 머지 URL · run.bat 금지 | Cursor **자동 로드 대상이 아님** → 자주 누락 |
| PR #140 `AGENTS.md` (미머지) | 보고 5항목 · 버전 · SR 링크 | main에 없음 · 머지 URL/run.bat 규칙 미포함 |
| `docs/일별_사용자요건/README.md` | SR 파일 형식 | 길어서 매 작업마다 전부 읽기 어려움 |
| 런 제목만 있는 세션 | 예: “Instruction clarity assessment” | **원문 없음** → 에이전트가 탐색만 반복 |

## 핵심 판정

1. **규칙이 세 곳에 쪼개져 있음** → 일부만 읽고 보고 폼·머지 URL·run.bat 금지를 빼먹음.
2. **`docs/에이전트_안내.md` 만으로는 부족** → Cursor가 기본으로 읽는 것은 루트 `AGENTS.md`.
3. **원문 없는 요청에 대한 행동이 정의되지 않음** → “일해라”만 오면 추측 구현·무한 탐색이 발생.
4. **문서만 변경 시 버전 올림 여부**가 불명확했음 → `AGENTS.md` 에 “문서만이면 동일 버전” 명시.
