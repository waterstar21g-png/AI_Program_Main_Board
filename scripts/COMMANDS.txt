AI_Program_Main_Board — 프로젝트별 독립 실행 명령
================================================

P1 / P2 / P3 는 서로 묶이지 않습니다.
각 프로젝트만 골라 실행하며, 아래 "명령 순서"는 그 프로젝트 안의 단계입니다.

------------------------------------------------
P1_Category_Url_Extract (독립)
------------------------------------------------
명령:
  p1.bat
  npm run p1
  node scripts/run-p1.mjs

명령 순서:
  1) 수집 실행          — ABC마트 카테고리 crawl
  2) 데이터 검증        — URL(http) · 상위최종라벨
  3) 결과 요약

보드: 좌측 [① P1 실행·검증]

------------------------------------------------
P2_Product_Capture_App (독립)
------------------------------------------------
명령:
  p2.bat
  npm run p2
  node scripts/run-p2.mjs

명령 순서:
  1) 모듈·워크플로 점검
  2) 샘플 엑셀 파싱 실행
  3) 데이터 검증        — 라벨 / URL 필드 분리
  ※ 실제 더망고 수집은 보드 P2 화면 ①→②

보드: 좌측 [② P2 실행·검증]

------------------------------------------------
P3_Python_Item_Collector (독립)
------------------------------------------------
명령:
  p3.bat
  npm run p3
  node scripts/run-p3.mjs

명령 순서:
  1) 파일·Python 환경 점검
  2) collect.py 구문 검사
  3) 데이터 검증        — 샘플 엑셀 openpyxl 읽기
  ※ 실제 더망고 수집은 python-collector\run.bat 에 엑셀 드래그

보드: 좌측 [③ P3 실행·검증]

------------------------------------------------
PowerShell 대체 (보드 버튼 / 로컬)
------------------------------------------------
  ① 동기화     ≈  .\run.ps1 -Sync
  ② 캐시정리   ≈  .\run.ps1 -Clean
  ③ 개별점검묶음 ≈  P1,P2,P3 를 각각 독립 실행 후 결과만 모음
                    (연쇄 파이프라인 아님)
