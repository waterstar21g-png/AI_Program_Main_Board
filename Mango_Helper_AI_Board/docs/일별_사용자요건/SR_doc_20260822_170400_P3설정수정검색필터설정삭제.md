## 반영 내용

### 신설 `P3_필터단위_설정수정_검색필터설정삭제/`

`P3_필터단위_수집조건수정` 을 복제한 뒤, 목록·팝업 조작은 이미 검증된
`P5_101_카테고리매핑_필터세부설정`(`map_categories.py`) 의 코드를 재사용했다 — 두
화면(목록 `admin_group.php`, `market_mapping_new` 팝업, `admin_category_set.php`)이
동일해서 로직을 새로 만들 필요가 없었고, 앞서 여러 차례(행 스캔·프레임 탐색·행 번호
확인) 고친 안정판을 그대로 물려받는다.

| 파일 | 내용 |
|------|------|
| `delete_filter_settings.py` | 본체 — `map_categories` import 해 재사용 |
| `run.bat` · `__init__.py` · `README.md` | 실행·패키지·설명 |
| `tests/test_delete_filter_settings.py` | 단위테스트 9건 |

### 입력 (스크린샷 1번)

- 수집사이트명 (비우면 화면에 이미 선택된 사이트 유지)
- 작업 목록 URL — 작업 시작 시 **[선택조건으로 검색하기]** 자동 클릭
- 작업 행 범위 [부터]-[까지] (1부터, 양끝 포함)

### 동작 (스크린샷 2·3번)

행 범위 안에서 순서대로:

1. **[설정수정]**(`onclick="market_mapping_new('<ftid>')"`) 클릭 → 팝업
   (`admin_category_set.php?tm=F&ps_ftid=<ftid>`)
2. 팝업에서 **[검색필터 설정삭제]**(`onclick="config_remove('','Y')"`) 클릭
3. 팝업 닫기 → 다음 행

팝업 클릭이 막히면 URL 을 직접 열고, 삭제 버튼을 못 찾으면 `config_remove('','Y')`
를 직접 호출한다. 실패해도 팝업은 반드시 닫고 다음 행으로 넘어간다.

### 부가 — 몇 번째 행인지 확인

P5_101 에서 만든 `--list-rows`(행 목록 확인) 기능을 그대로 물려받아, 삭제 없이
행 번호·ftid·필터명을 먼저 확인할 수 있다.

### 보드

**P3_설정수정_검색필터삭제** 탭 — 사이트·목록URL·행범위 입력,
[행 목록 확인] · **[삭제 시작]**(되돌릴 수 없음 확인 대화상자) · [작업중단].
탭 안내에도 "⚠ 되돌릴 수 없는 삭제 작업" 경고를 상시 표기했다.
