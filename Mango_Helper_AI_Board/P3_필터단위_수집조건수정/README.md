# P3_필터단위_수집조건수정

`P2_필터단위_상품수변경` 을 복제해, 입력값을 **번역옵션(리스트박스 선택)** 으로
바꾼 프로그램입니다. 더망고 **필터 목록**의 각 행에 선택한 번역옵션을 일괄 적용합니다.

## 입력

- **번역옵션** — 리스트박스에서 하나 선택 (숫자 입력 아님)
  - 목록은 망고 수집조건수정 화면의 실제 옵션을 읽어옵니다
    (보드 **[망고에서 옵션 읽기]** 또는 `--list-options`)
  - 읽어온 목록은 `.translate_options.json` 에 캐시되어 다음 실행 때 그대로 뜹니다
- **망고 URL** — 비우면 Chrome 에 열려 있는 필터 목록 화면 사용

## 동작

1. 필터 목록 화면 연결
2. 수정 가능한 각 행에 대해:
   - 수집조건수정 → **번역옵션 선택값 적용** → 저장하기 → 확인
3. 다음 행 순차 처리

번역옵션 컨트롤은 화면 형태에 따라 **드롭다운(select) · 라디오 · 체크박스** 중
무엇이든 자동 판별합니다 (`번역후저장`·`번역옵션`·`번역` 라벨 기준). 적용 후 값을
다시 읽어 확인하고, 확인 실패 시 그 행은 실패로 남깁니다.

## CLI

```powershell
python update_collect_option.py --list-options
python update_collect_option.py --translate-option "번역후저장"
python update_collect_option.py --translate-option "번역후저장" --mango-url "https://..."
```

`--list-options` 출력은 한 줄에 `##OPTION##<옵션명>` 형식이며, 보드가 이 줄만
파싱해 리스트박스를 채웁니다.
