이전(1.6.0): P3_필터단위_수집조건수정 — 수집사이트 리스트박스 · 팝업 저장 흐름 · 첫화면 URL.
1) 입력 리스트박스 2개: 수집사이트(select[name=site_id] — 4910.kr /
   ABCmart.a-rt.com / HIVER.co.kr / MUSINSA.com / Zara.com/de) + 번역옵션.
   수집사이트를 고르면 목록 화면에 검색을 걸고 그 결과 행만 처리한다.
2) 실제 흐름대로 재구현: 행의 [수집조건수정](modify_filter(fuid)) → 팝업창
   (/mall/admin/admin_group_modify.php?ps_mode=modify_filter&ps_fuid=…) →
   번역 후 저장 선택 → 하단 [저장하기](set_save()) → 알림 자동확인 →
   팝업(window.close()) 닫힘. 목록 페이지를 떠나지 않아 검색조건이 풀리지 않는다.
3) 첫 화면 URL 기본값: https://tmg1898.cafe24.com/mall/admin/shop/getGoodsCategory.php
4) 폴백: 팝업 클릭 실패 시 팝업 URL 직접 오픈, 저장 버튼 미검출 시 set_save() 호출.
