# 비즈보드 v1.0.0

완전히 독립 실행되는 모바일 **비즈보드** PWA입니다.  
(기존 `board/` Python 메인보드·P1/P2/P3와 분리)

## 기능

1. **휴대폰 홈 아이콘** — PWA(홈 화면에 추가 / 앱 설치)
2. **20개 이상 바로가기 URL** — 보드에서 타일 클릭
3. **사전 정의 ID/PW 로그인** — 설정에 저장 → 클릭 시 자동 로그인 절차

## 실행 (로컬)

```bash
# 저장소 루트에서
python3 비즈보드/serve.py
```

브라우저에서 `http://127.0.0.1:8787` 접속.

Windows:

```bat
비즈보드\실행.bat
```

## 휴대폰 홈에 아이콘

1. 휴대폰 브라우저로 배포 URL(또는 같은 Wi-Fi의 PC 주소) 접속
2. **iPhone Safari**: 공유 → **홈 화면에 추가**
3. **Android Chrome**: 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
4. 홈의 **비즈보드** 아이콘 클릭 → 바로가기 보드

## ID/PW 설정

1. 보드 → **ID/PW 설정**
2. 사이트별 아이디·비밀번호 입력 후 **저장** (기기 localStorage만 사용)
3. 보드에서 타일 클릭 → 로그인 절차 수행
   - `post` 사이트: 폼 자동 전송
   - `open` 사이트: ID/PW 복사 + 로그인 페이지 보조

## 파일

| 경로 | 역할 |
|------|------|
| `index.html` | 바로가기 보드 |
| `auth.html` | 로그인 브릿지 |
| `settings.html` | ID/PW 사전 정의 |
| `js/sites.js` | 20+ URL 정의 |
| `manifest.webmanifest` | 홈 아이콘 PWA |
| `sw.js` | 오프라인 캐시 |

## 사이트 추가

`js/sites.js`의 `BIZ_BOARD_SITES` 배열에 항목을 추가하면 됩니다.
