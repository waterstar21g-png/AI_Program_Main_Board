# P1_101 상품수 추출

엑셀 URL을 열어 **팝업 닫기 → 푸터까지 고속 하향 → 하단→상단 고속 상향하며 카드 갯수 집계** 후
동일 엑셀 `총상품수`를 UPDATE 합니다.

## 보드 (직접 실행)

좌측 **P1_101 상품수 추출** → `엑셀자료 파일지정` → **▶ 상품수 추출 실행**

## 흐름 (행마다)

1. URL 열기 후 **첫번째 팝업창 닫기**
2. 스크롤 **상단 → 푸터**까지 최대한 빠르게 내린다 (집계 없음)
3. 스크롤 **하단 → 상단**으로 최대한 빠르게 올리며 **카드 갯수**를 센다
4. 그 갯수를 상품수로 **엑셀·실행로그**에 출력

## 실행로그 최종출력

```
[최종] 상위 최종 카테고리명=MEN 스니커즈 · 상품갯수=77 · url=https://...
```
