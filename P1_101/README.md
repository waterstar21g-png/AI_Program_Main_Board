# P1_101 상품수 추출

엑셀에 담긴 URL을 열어 **팝업 닫기 → 3초 대기 → 상품수 수집** 후,
동일 엑셀의 `총상품수` 열을 UPDATE 합니다.

## 보드 (직접 실행)

`run.bat` → 좌측 **P1_101 상품수 추출** → `엑셀자료 파일지정` → **▶ 상품수 추출 실행**

- 별도 CLI/`P1_101/run.bat` 없이 **메인보드에서 직접 실행**
- 실행 로그는 보드 그리드에 실시간 표시
- **중단** 버튼으로 중도 종료(현재까지 UPDATE 저장)

## CLI

```bat
cd P1_101
python extract.py D:\path\to\category.xlsx
python extract.py D:\path\to\category.xlsx --headless
```

## 엑셀

- URL 열: `최종 카테고리 URL주소` (없으면 URL/http 열 자동 탐지)
- 상품수 열: `총상품수` (없으면 자동 추가)
- `상품수집가능개수` 열이 이미 있으면 동일 값으로 함께 UPDATE

## 흐름 (행마다)

1. URL 열기
2. 팝업/레이어/추가창 닫기
3. **3초 대기**
4. 화면에 노출된 상품수 파싱
5. 엑셀 해당 행 UPDATE → 저장
