# P1_101 상품수 추출

엑셀 URL을 열어 **팝업 닫기 → 푸터까지 하향 → 하단→상단 상향하며 카드 갯수 집계** 후
출력 폴더에 **별도 파일(파일명+버전)** 로 저장합니다. (입력 엑셀은 수정하지 않음)

## 출력 위치

`D:\My_Project\AI_Program_Main_Board\P2_INPUT_건수집계`

파일명 예:

```
원본이름_상품수_v2.0.96_20260812_151543.xlsx
```

## 보드 (직접 실행)

좌측 **P1_101 상품수 추출** → `엑셀자료 파일지정` → **▶ 상품수 추출 실행**

## 흐름 (행마다)

1. URL 열기 후 **첫번째 팝업창 닫기**
2. 스크롤 **상단 → 푸터**
3. 스크롤 **하단 → 상단** · **카드 갯수** 집계
4. 상품수를 엑셀·실행로그에 기록 → 출력 폴더에 저장

## 실행로그 최종출력

```
[최종] 상위 최종 카테고리명=MEN 스니커즈 · 상품갯수=77 · url=https://...
```
