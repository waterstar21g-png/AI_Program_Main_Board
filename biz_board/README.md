# 비즈보드 (독립 실행)

휴대폰 홈 화면 아이콘 → **20개 이상 바로가기 URL** → 사전 정의 **ID/PW**로 로그인 절차 수행.

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 바로가기 보드 (PWA) |
| `login.html` | 로그인 절차 실행 |
| `config.js` | 기본 24개 URL 목록 |
| `serve.py` / `run.bat` | 로컬 서버 (휴대폰 LAN 접속) |

## 휴대폰 홈에 아이콘 만들기

1. PC에서 `biz_board/run.bat` 실행 (또는 `python serve.py`)
2. 휴대폰 브라우저로 `http://<PC-IP>:8787/` 접속
3. **홈 화면에 추가**
   - Android Chrome: 설치 배너 또는 메뉴 → 홈 화면에 추가
   - iPhone Safari: 공유 → 홈 화면에 추가
4. 홈 아이콘 **비즈보드** 클릭 → 바로가기 목록

## ID/PW 설정

1. 보드 상단 **ID/PW 설정**
2. 각 서비스 계정 입력 후 **저장** (이 기기 localStorage만 사용)
3. 타일 클릭 → 로그인 절차 자동 실행
   - `form_post` 서비스: 폼 전송으로 로그인 시도
   - 그 외: ID 복사 → 로그인 URL 열기 → PW 복사

## 바로가기 추가

**바로가기 추가** 버튼으로 사용자 정의 URL을 더 넣을 수 있습니다.
