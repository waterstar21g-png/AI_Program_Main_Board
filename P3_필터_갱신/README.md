# P3_필터_갱신

더망고 **검색필터(저장조건)** 화면에서 엑셀의 상품수집가능개수를 기준으로
**저장상품수**를 갱신합니다.

## 보드

좌측 **P3_필터_갱신** — UI는 P2와 유사:

1. 디렉터리 파일 목록에서 엑셀 선택  
2. **더망고 URL** — `getGoodsCategory.php?pmode=filter_delete&…&site_id=zara_de…` 고정 초기값  
3. 카테고리URL목록 확인 → **작업시작**  
4. **P2와 동일** — 망고 Chrome(CDP) 창을 화면에 띄운 뒤 검색필터 URL로 이동  
5. 필터 매칭 시 — 스토어/수정 팝업을 창 앞으로 가져와 동작을 보여 줌

## 저장상품수 규칙

| 상품수집가능개수 | 저장상품수 |
|------------------|------------|
| ≤ 200 | 그대로 |
| 201 ~ 500 | 300 |
| > 500 | 400 |
