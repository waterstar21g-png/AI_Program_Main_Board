# P3_필터_갱신

더망고 **검색필터(저장조건)** 화면에서 엑셀의 상품수집가능개수를 기준으로
**저장상품수**를 갱신합니다.

## 보드

좌측 **P3_필터_갱신** — UI는 P2와 유사:

1. 디렉터리 파일 목록에서 엑셀 선택  
2. **더망고 URL** — 검색필터(저장조건) 화면 URL이 초기값으로 채워짐 (참고·기억용)  
3. 카테고리URL목록 확인 → **작업시작**  
4. **현재 열린 망고 화면**에서만 진행 (로그인·URL 진입 없음)  
5. 필터 매칭 시 — 팝업/탭을 실제 Chrome에 표시하며 단계 진행

## 저장상품수 규칙

| 상품수집가능개수 | 저장상품수 |
|------------------|------------|
| ≤ 200 | 그대로 |
| 201 ~ 500 | 300 |
| > 500 | 400 |
