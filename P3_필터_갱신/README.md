# P3_필터_갱신

더망고 **검색필터(저장조건)** 화면에서 엑셀의 상품수집가능개수를 기준으로
**저장상품수**를 갱신합니다.

## 보드

좌측 **P3_필터_갱신** — UI는 P2와 유사:

1. 디렉터리 파일 목록에서 엑셀 선택  
2. **더망고 URL** — 망고 URL이 기본으로 채워짐 (필요 시 수정, 변경값 기억)  
3. 카테고리URL목록 확인 → **작업시작**

## 저장상품수 규칙

| 상품수집가능개수 | 저장상품수 |
|------------------|------------|
| ≤ 200 | 그대로 |
| 201 ~ 500 | 300 |
| > 500 | 400 |
