# P2 — 더망고 상품데이터 대량수집 (Python)

목표: **카테고리 URL 1행 → 상품 3건**을 오류 없이 가져오기.

## 1행 검증 (추천)

```bat
run-verify.bat 엑셀.xlsx
```

보드: **「1행 검증 모드」** 체크 후 실행.

- 첫 행만 · 단계 스크린샷(`run-logs/`) · 같은 행 재시도 3회
- 저장수 3 입력 확인 · 저장 후 오류 문구 검사

## 일반

```bat
run.bat 엑셀.xlsx
python collect.py 엑셀.xlsx 3 --retries 3 --yes
```

로그인: 더망고 로그인창에서 **사용자가 직접** 입력 (자동 입력 없음).

Chrome 기동 시 **더망고 솔루션** 확장프로그램에 아래 값을 자동 입력·저장합니다.

- 더망고 서비스 URL: `https://tmg1898.cafe24.com`
- 서비스 인증 KEY: (코드에 고정 — `collect.py` 의 `MANGO_SERVICE_*`)

보드 **[수집 종료]** 로 중도 중단 가능(실행로그 화면 보존).  
입력 1번은 행당 제한시간(기본 180초)·확정실패 시 같은 행을 무한 반복하지 않고 다음 입력으로 넘어갑니다.  
2번(이후) 수집 전, 열린 팝업/모달이 **모두 종료될 때까지 대기**한 뒤 스크린샷(`00_overlays_clear`)을 보관하고 진행합니다.  
두 버튼은 **반드시 둘 다** 실행합니다 (다른 버튼임).

1. **[버튼1]** 결과목록 상단 `검색된 상품 모두저장` → 상품저장설정 모달 열림  
2. 검색필터명·저장상품수 입력  
3. **[버튼2]** 모달 하단 파란 `저장하기`(옆 `취소하기`) → 서버 최종 갱신  

버튼2는 취소하기 옆 푸터 쌍으로만 찾고, `모두저장`/`선택상품저장`과 절대 혼동하지 않습니다.  
반응 없으면 **최대 1회 재시도** 후 다음 행. 성공 시 **「N건이 수집되었다」** 검증.

엑셀 헤더: `상위 최종 카테고리명` | `최종 카테고리 URL주소`
